# 🌍 World of Football
<img width="943" height="549" alt="image" src="https://github.com/user-attachments/assets/cb8715e0-9d32-4881-90c0-a44b08990ca4" />
World of Football is a football statistics web application built as a 
bachelor's thesis project. It covers national team data across multiple 
continents — Africa, South America, and North America (CONCACAF) — and 
provides detailed match statistics, standings, player market values, 
and lineup information for each team.

## Features

- 📊 National team statistics across 3 continents (28+ teams)
- 🏆 Live and historical match data with detailed stats and lineups
- 💰 Player market values scraped from Transfermarkt
- 🎥 Match highlight videos via YouTube Data API
- 🤖 Integrated AI chatbot powered by Google Gemini
- 🔐 User authentication system (register, login, logout)
- 💬 Chat history saved per user with search functionality

## Tech Stack

- **Backend:** Python, Flask, SQLAlchemy
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Jinja2
- **APIs:** Sofascore (via RapidAPI), YouTube Data API v3, Google Gemini
- **Scraping:** BeautifulSoup (Transfermarkt)
